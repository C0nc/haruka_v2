# Figure 2 — benchmark on the paired mouse-brain simulation

**Claim.** Haruka recovers background anatomy and condition-specific salient domains
together; methods that model only one of the two fail on the other.

## Draft legend

**Fig. 2 | Benchmark on a paired simulation with planted ground truth.**
**a**, Ground truth for a representative section (B5): seven background subregions
(top) and three salient domains planted only in the disease arm (bottom).
**b**, Domains recovered by each method on the same section; colours show the
ground-truth class each predicted cluster overlaps most. Maps show the disease arm.
Expression + neighbourhood aggregation lets the perturbation leak into the background
map; scVI + CellCharter recovers anatomy in place of the salient domains.
**c, d**, Adjusted Rand index for background subregions (**c**) and salient domains
(**d**) across n = 5 independent section pairs.
**e**, Paired per-section difference between Haruka and each comparator; labels give
the number of sections in which Haruka scored higher.

## Statistics

- n = 5 section pairs (simulated tissues A8, A9, B17, B3, B5); one point per section.
- Box: interquartile range; centre line: median; whiskers: 1.5 × IQR; points: sections.
- Scoring, identical for every method: raw saved spatial embedding → KMeans,
  k = number of planted classes, `random_state=0`, `n_init=20`. Background ARI over
  both arms (157,412 cells in B5); salient ARI over the disease arm (78,706 cells).
- **No hypothesis test is reported.** With n = 5 a two-sided paired Wilcoxon test
  cannot go below p = 0.0625, so section win counts are shown instead (panel e).
- Means ± s.d. (background / salient): Haruka 0.540 ± 0.046 / 0.854 ± 0.124;
  CINEMA-OT + CC 0.510 ± 0.041 / 0.816 ± 0.052; Expression + aggregation
  0.339 ± 0.089 / 0.815 ± 0.052; scVI + CC 0.479 ± 0.018 / 0.139 ± 0.171;
  ContrastiveVI + CC 0.474 ± 0.028 / 0.022 ± 0.023.

## Reviewer-risk notes (state these, don't hide them)

- The margin over the strongest baseline (CINEMA-OT) is small: background 5/5 sections
  but by ≤0.07 ARI; salient 4/5, with B3 reversed (0.638 vs 0.756).
- "Haruka" is the composition-gated model at λ = 10. λ was chosen from a sweep run on
  these same five simulated sections, so the Haruka numbers are mildly optimistic;
  other λ values (5–25) give balanced recovery 0.686–0.697, so the conclusions do not
  depend on the choice. Other Haruka variants are not shown in this figure.
- Representative section chosen by rule, not by eye: B5 is the median of Haruka's
  per-section balanced score.
